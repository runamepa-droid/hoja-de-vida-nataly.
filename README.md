# Hoja de vida digital — Ruth Nataly Meza Palacios

Sitio estático en HTML y CSS, adaptable a móviles y listo para publicar en GitHub Pages o Vercel.

## Publicar en GitHub
1. Crea una cuenta en https://github.com/ si aún no tienes una.
2. Crea un repositorio nuevo, por ejemplo `hoja-de-vida-nataly`.
3. Sube `index.html` a la raíz del repositorio.
4. En GitHub, abre **Settings → Pages** y selecciona `Deploy from a branch`, rama `main`, carpeta `/root` (si deseas usar GitHub Pages).

## Publicar en Vercel
1. Entra a https://vercel.com/ y elige **Continue with GitHub**.
2. Autoriza la conexión y selecciona **Add New → Project**.
3. Importa el repositorio `hoja-de-vida-nataly`.
4. Como es una página HTML estática, no necesitas framework ni comando de build. Deja el directorio raíz como `./` y despliega.
5. Vercel te entregará una URL pública que podrás compartir en tu hoja de vida.

## Antes de publicar
- Revisa que el teléfono, correo y enlaces estén correctos.
- Completa los cargos, funciones y logros específicos de cada empresa: no se inventaron porque no estaban incluidos en la información inicial.
- Si tienes un perfil de GitHub, agrega el enlace cuando lo tengas.
- Puedes reemplazar textos y colores directamente en `index.html`.
